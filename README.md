# Tata Power – Financial Modelling & Valuation Analysis

## 🚧 Project Status
**Ongoing Project**

## 📌 Project Overview

This project focuses on the financial modelling and valuation analysis of Tata Power Company Limited.

The analysis combines historical financial performance, financial forecasting, profitability, leverage and valuation to assess the company's future financial outlook.

## 🎯 Project Objective

- Analyse historical financial performance
- Develop forward-looking financial forecasts
- Analyse revenue growth and profitability
- Evaluate operating expenses and leverage
- Build a financial model
- Perform valuation and sensitivity analysis

## 🌱 Key Focus Area

The analysis also considers Tata Power's growing focus on **renewable energy** and its potential impact on future revenue growth, profitability and capital requirements.

## 📊 Analysis Areas

- Historical Financial Analysis
- Financial Forecasting
- Profitability & Margin Analysis
- Leverage Analysis
- Financial Modelling
- Valuation Analysis
- Sensitivity Analysis
